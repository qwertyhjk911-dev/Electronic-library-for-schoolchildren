# Электронная библиотека для школьников
# Введение
Данный документ является описанием индивидуального итогового проекта «Электронная библиотека для школьников», выполненного в рамках предметной области IT-проекты.
В современной школе учебники остаются основным инструментом обучения. Однако нередко возникают ситуации, когда нужный учебник недоступен: забыт дома, утерян или не куплен. Ученику приходится искать материал в интернете — и здесь он сталкивается с другой проблемой: доступные ресурсы перегружены рекламой, требуют регистрации или содержат учебники лишь по отдельным предметам.
В рамках данного проекта был создан многостраничный веб-сайт, объединяющий учебники с 1 по 11 класс по всем основным предметам в едином удобном пространстве — бесплатно и без регистрации.

# Цель
Разработать многостраничный бесплатный веб-сайт, предоставляющий школьникам 1–11 класса удобный и мгновенный доступ к учебникам по всем предметам в одном месте — без регистрации и рекламы.

# Задачи
1.	Изучить существующие интернет-ресурсы с учебниками и выявить их основные недостатки.
2.	Создать прототип сайта в программе Figma: спроектировать структуру страниц, навигацию и визуальный стиль.
3.	Разработать HTML-код тринадцати страниц сайта (главная страница и страницы для каждого класса с 1 по 11).
4.	Создать единый файл стилей CSS, обеспечивающий единообразный внешний вид всего сайта.
5.	Найти и проверить рабочие прямые ссылки на учебники в формате PDF для каждого класса и каждого предмета.
6.	Протестировать сайт: проверить корректность навигации, работу ссылок и отображение в различных браузерах.

# Описание проекта

# О проекте
«Электронная библиотека для школьников» — это информационный веб-сайт, предназначенный для обеспечения свободного и бесплатного доступа к школьным учебникам. Сайт адресован ученикам 1–11 класса, а также их родителям и учителям.
Сайт не требует подключения к интернету в процессе использования на устройстве пользователя, работает локально и открывается в любом современном браузере.
Структура сайта
Сайт состоит из тринадцати HTML-страниц:
Главная страница (Menu.html)

—	Главная страница (Menu.html) — содержит описание библиотеки, навигационное меню по классам и главное изображение.
—	Страницы классов (1_class.html — 11_class.html) — одиннадцать отдельных страниц, по одной для каждого класса. Каждая страница содержит полный список предметов, изучаемых в данном классе, с прямыми ссылками на соответствующие учебники.
Навигация по сайту осуществляется двумя способами: горизонтальное меню классов в верхней части каждой страницы и фиксированное вертикальное меню предметов, закреплённое на экране при прокрутке. На каждой странице присутствует кнопка «Вверх», возвращающая пользователя к началу страницы.

# Контент
На каждой странице класса размещены прямые ссылки на учебники в формате PDF. Всего на сайте собрано более 150 ссылок, охватывающих следующие предметы:
—	1–4 классы: Русский язык, Математика, Литературное чтение, Родной язык, Литературное чтение на родном языке, Окружающий мир, Иностранный язык (со 2 класса), Физическая культура, Изобразительное искусство, Музыка, Технология, ОРКСЭ (4 класс).
—	5–9 классы: Русский язык, Литература, Родной язык, Родная литература, Иностранный язык, Математика / Алгебра / Геометрия, Вероятность и статистика, Информатика, История, История России, География, Биология, Физика (с 7 класса), Химия (с 8 класса), Обществознание (с 8 класса), Физическая культура, ИЗО, Музыка, Технология, ОБЗР (с 8 класса), ОДНКНР (5–6 класс).
—	10–11 классы: Русский язык, Литература, Иностранный язык, Алгебра и начала математического анализа, Геометрия, Вероятность и статистика, Информатика, История, История России, География, Биология, Физика, Химия, Обществознание, Физическая культура, ОБЗР, Технология.
Ссылки ведут на PDF-файлы, размещённые на открытых ресурсах: официальных сайтах образовательных учреждений (домены gosuslugi.ru, gosweb.gosuslugi.ru), публичных хранилищах документов и других общедоступных источниках. Все ссылки проверены на работоспособность в процессе тестирования.

# Средства создания
Для разработки сайта использовались следующие инструменты и технологии:
7.	HTML5 — язык разметки, определяющий структуру и содержимое каждой страницы сайта.
8.	CSS3 — каскадные таблицы стилей, задающие единообразный визуальный стиль всех страниц. Все стили вынесены в единый файл Css.css.
9.	Notepad++ — редактор кода с подсветкой синтаксиса, использовавшийся для написания и редактирования HTML и CSS.
10.	Figma — инструмент прототипирования интерфейсов, применявшийся на этапе проектирования для разработки макета сайта до начала вёрстки.
11.	Браузер — для тестирования корректности отображения сайта.

# Технические особенности
Сайт реализован без использования сторонних библиотек и фреймворков — весь код написан автором самостоятельно. Ключевые технические решения:
—	Фиксированное боковое меню предметов реализовано с помощью CSS-свойства position: fixed, что позволяет меню оставаться видимым при прокрутке длинных страниц.
—	Навигация внутри страницы (переход к разделу конкретного предмета) реализована через якорные ссылки с использованием HTML-атрибута id.
—	Единый файл стилей Css.css обеспечивает визуальное единообразие всех 12 страниц сайта без дублирования кода.

# Вывод
В результате работы над проектом был создан многостраничный веб-сайт «Электронная библиотека для школьников», реализующий поставленную цель: обеспечение бесплатного удобного доступа к школьным учебникам для учеников 1–11 класса без регистрации и рекламы.
Сайт включает 13 HTML-страниц, единый файл стилей CSS и более 150 проверенных ссылок на учебники в формате PDF по всем основным предметам. В процессе работы были освоены технологии HTML5 и CSS3, принципы построения многостраничных сайтов, работа с якорными ссылками, фиксированным позиционированием элементов и прототипированием в Figma.
Проект решает реальную задачу: школьник в любой момент может найти нужный учебник — быстро, бесплатно, без лишних шагов.
В дальнейшем планируется разместить сайт в сети интернет с использованием бесплатного хостинга GitHub Pages, добавить адаптивную вёрстку для корректного отображения на мобильных устройствах, а также реализовать поиск по предметам с использованием JavaScript.
